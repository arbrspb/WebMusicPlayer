# Универсальный конвейер анализа коллекции

Приложение не требует Rekordbox или видеокарты. Обязательным остаётся только
основной индекс `Librosa + RF`; остальные этапы подключаются независимо через
«Настройки → Центр обработки коллекции».

## Этапы

1. **Основной индекс — Librosa + RF.** Работает на CPU, формирует базовый жанр,
   BPM и компактные акустические признаки.
2. **YAMNet.** Необязательное уточнение аудиособытий и жанровой вероятности.
   Может использовать ONNX Runtime CUDA, при ошибке возвращается на CPU.
3. **Whisper.** Необязательное уточнение языка вокала. Использует CUDA только
   когда её видит `ctranslate2`, иначе остаётся на CPU.
4. **Discogs Multi-EffNet.** Отдельный глубокий индекс похожести. Он читает
   только отсутствующие или изменённые треки и не требует пересоздания основной
   базы. Результаты хранятся версионно в `track_deep_embeddings`.
5. **Персональная модель.** Учится по оценкам 1–5 звёзд. Источником могут быть
   оценки плеера, Rekordbox или оба источника. Rekordbox всегда опционален.

Аудиоэтапы 1–4 запускаются по очереди. Это защищает сетевой диск и оперативную
память от одновременного декодирования большой коллекции.

## Обычная установка CPU

В PyCharm выберите интерпретатор проекта `.venv` и установите
`requirements.txt`. Это переносимый вариант для любой системы. В «Устройство»
оставьте «Автоматически»: приложение покажет `CPUExecutionProvider`.

## Опциональная NVIDIA CUDA

После обычной установки замените CPU-пакет ONNX Runtime:

```powershell
python -m pip uninstall -y onnxruntime
python -m pip install -r requirements-cuda.txt
```

Наличие CUDA определяется во время запуска. Если `CUDAExecutionProvider`
недоступен или завершается ошибкой, YAMNet и EffNet безопасно работают на CPU.
Версия Python и другие виртуальные окружения при этом не меняются: пакеты
устанавливаются только в выбранную `.venv`.

## Порядок для новой или существующей базы

- Пустая база: основной индекс → интеллектуальный каталог → по желанию Whisper
  и EffNet → персональная модель.
- Существующая база: повторное основное сканирование не требуется. Сначала
  выполните «Добавить новые / обновить стили», затем запустите недостающие
  дополнительные индексы.
- После добавления новых файлов режим «Продолжить» добавит только изменения;
  каждый дополнительный индекс также обработает только недостающие записи.

Отключение EffNet, Whisper или Rekordbox не удаляет накопленные данные. Оно лишь
исключает компонент из новых вычислений, поэтому настройку можно вернуть без
повторной полной индексации.
